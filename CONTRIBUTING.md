All commits must be signed off (`git commit -s`) per the Developer Certificate of Origin.
See https://developercertificate.org for the full text.

Every Python and YAML file starts with `# SPDX-License-Identifier: Apache-2.0`. Run `pip install pre-commit && pre-commit install` once after cloning, and the `insert-license` hook in `.pre-commit-config.yaml` adds the header to new files.
