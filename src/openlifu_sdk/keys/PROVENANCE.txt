Trusted firmware signing keys (ECDSA P-256 public keys, PEM)
=============================================================

Used by OWComponent.firmware_domain() to tell which key signed the firmware
a device is running (OW_CMD_SIGCHK), and so whether it is a research or a
clinical build. Public keys only: nothing here can sign. Fingerprints are
SHA-256 over the DER SubjectPublicKeyInfo; unit-test/test_firmware_domain.py
pins them, so replacing a file fails CI until that test is updated too.

Each board's bootloader trusts exactly one of these keys: the research
bootloader the research key, the clinical bootloader the clinical key.
